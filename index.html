Questions

Good to know.

Is it really free?

Yes. No subscription, no trial, no premium tier. Akoway is MIT-licensed open source, and the speech models are open too.

Does it need the internet?

Only once, to download the speech model the first time you open it. After that it works fully offline, even in airplane mode.

Is my voice uploaded anywhere?

Never. Your audio is turned into text on your own device and then thrown away. There's no account and no analytics.

How do I start it on Windows?

Double-tap Ctrl from any app and the Akoway pill appears; click the mic and talk. You can also use Ctrl + Alt + F9, or set your own shortcut in Settings. Akoway just needs to be running: it sits quietly in the system tray, and the installer can start it with Windows so it's always ready.

How do I install the Android app?

Download the APK on your phone, open it, and allow installs from your browser when Android asks. Then open Akoway and follow the three setup steps. The optional floating tab uses Accessibility; if it's greyed out, open Settings › Apps › Akoway › ⋮ › Allow restricted settings.

Which languages does it support?

English for now. Bark 3.0 is an English speech model.

Is there a Mac or iPhone version?

Not yet. The code is open, so a Mac or Linux port is welcome: see it on GitHub.
